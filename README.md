# 놀이게임

제시어로 하는 놀이 두 가지를 진행해 주는 아이패드용 웹앱입니다.
아이패드 홈 화면에는 **놀이게임**이라는 이름으로 설치됩니다.

| 게임 | 어떤 놀이인지 |
|---|---|
| **몸으로 말해요** | 초등학교 2~5학년 아이들과 하는 제스처 게임. 스케치북 대신 앱이 제시어를 보여줍니다 |
| **라이어 게임** | 한 명만 제시어를 모른 채 아는 척하고, 나머지가 그 사람을 찾아내는 놀이 |
| **폭탄 돌리기** | 초성이나 주제에 맞는 말을 대고 옆 사람에게 넘기다가, 폭탄이 터진 사람이 지는 놀이 |
| **술래 정하기** | 손가락을 올리거나 이름을 넣어서 술래를 뽑는 도구 |

몸으로 말해요와 라이어 게임은 **같은 제시어 데이터**를 함께 씁니다. 제시어를 늘리면 양쪽에서 다 쓰입니다.
폭탄 돌리기는 낱말 하나가 아니라 답이 여럿인 조건을 내는 놀이라서 **따로 준비된 초성·주제**를 씁니다.

인터넷 없이 돌아가고, 로그인이나 서버가 필요 없습니다. 모든 기록은 아이패드 안에만 저장됩니다.

## 아이패드에 설치하기

한 번만 해 두면 다음부터는 앱처럼 아이콘을 눌러서 바로 열립니다.

1. **사파리**로 앱 주소를 엽니다. 크롬이 아니라 사파리여야 합니다.
2. 화면 위쪽의 **공유 단추**(네모에 위쪽 화살표)를 누릅니다.
3. 목록을 아래로 내려 **홈 화면에 추가**를 누릅니다.
4. 이름을 확인하고 오른쪽 위 **추가**를 누릅니다.
5. 홈 화면에 생긴 아이콘을 누르면 사파리 주소창 없이 **전체 화면**으로 열립니다.

설치한 뒤 앱을 한 번 실행하면 필요한 파일이 아이패드에 저장돼서, 그다음부터는
**비행기 모드나 인터넷이 안 되는 곳에서도** 게임을 끝까지 할 수 있습니다.

### 게임하기 전에 확인할 것

- **가로로 들고** 쓰면 제시어가 가장 크게 보입니다. 세로로 써도 동작합니다.
- 아이패드 옆면의 **무음 스위치**가 켜져 있으면 효과음이 나지 않습니다.
- 게임 중에는 화면이 저절로 꺼지지 않습니다.
- **화면 회전 잠금**을 걸어 두면 아이들이 기기를 돌려도 화면이 뒤집히지 않습니다.

## 몸으로 말해요

설명하는 사람이 아이패드를 자기 쪽으로 들고 화면의 제시어를 확인한 뒤 몸짓이나 말로 설명하고,
맞히는 사람은 화면을 보지 않습니다.

### 팀 대항전

팀을 2~4개로 나누고 번갈아 설명합니다. 팀마다 제한 시간이 따로 주어지고,
시간 안에 많이 맞힌 팀이 이깁니다.

### 릴레이전 (단체)

편을 가르지 않는 **협동전**입니다. 참가자 2~8명이 하나의 팀이 되어,
**제한 시간 하나를 다 같이 나눠 씁니다.**

- 각자 정해진 개수만큼 맞혀야 합니다.
- 시간 안에 전원이 자기 몫을 채우면 **통과**입니다.
- 기기를 다음 사람에게 넘기는 동안에는 시간이 멈춥니다.
- **패스**는 아직 몫이 남았을 때 누르면 제시어만 바뀌고, **마지막 한 개가 남았을 때**
  누르면 그 제시어를 그대로 다음 사람이 이어받습니다. 못 채운 몫은 남아서 다시 돌아옵니다.

### 공통 설정

주제(복수 선택), 난이도(쉬움 / 어려움 / 섞기), 설명 방식(몸으로만 / 말 설명 허용),
제한 시간, 패스 허용 횟수, 힌트 사용 여부를 게임 시작 전에 고릅니다.

**주제는 늘 아무것도 선택되지 않은 상태로 열립니다.** 그날 할 주제만 골라 쓰라는 뜻이고,
나머지 설정은 지난번에 쓰던 값을 그대로 기억합니다. 라이어 게임도 마찬가지입니다.

설정 화면 아래쪽에 **이 조건으로 몇 판까지 같은 제시어가 안 나오는지** 미리 알려줍니다.

## 라이어 게임

3~10명이 기기 하나를 돌려 가며 하는 놀이입니다. 사회자가 따로 없어도 앱이 진행을 맡습니다.

### 진행 순서

1. **제시어 확인** 기기를 한 사람씩 넘겨받아 화면을 **꾹 누르고 있는 동안에만** 내용을 봅니다.
   한 명에게만 '당신은 라이어입니다'가 뜨고, 나머지는 제시어를 봅니다. 손을 떼면 바로 가려집니다.
2. **설명** 앉은 순서대로 한 명씩 제시어를 돌려서 설명합니다.
   판마다 시작하는 사람만 무작위로 바뀌고, 그다음부터는 옆 사람으로 넘어갑니다.
   8명이 있고 5번부터 시작하면 5, 6, 7, 8, 1, 2, 3, 4 순서입니다.
   제시어를 확인할 때와 투표할 때도 같은 순서로 돌아서 기기를 넘기기 쉽습니다.
   라이어는 다른 사람 설명을 듣고 제시어를 짐작해서, 아는 척 자기도 설명해야 합니다.
   너무 정확히 설명하면 라이어에게 답을 알려 주는 셈이고, 너무 모호하면 자기가 의심받습니다.
3. **투표** 정해진 바퀴를 다 돌면 라이어로 의심되는 사람에게 투표합니다.
4. **결과** 지목한 사람이 라이어였는지 시민이었는지부터 크게 알려 줍니다.
   라이어를 맞혔더라도 그 라이어가 제시어를 알아맞히면 뒤집어서 라이어가 이깁니다.
   시민을 지목했으면 아래 설정에 따라 한 번 더 기회를 얻거나 그대로 라이어가 이깁니다.

### 설정

| 항목 | 고를 수 있는 것 |
|---|---|
| 참가자 | 3~10명, 이름을 직접 넣을 수 있음. 둘러앉은 자리대로 번호를 정해 두면 좋습니다 |
| 말하는 순서 | 시계 방향(번호가 커지는 쪽) / 반시계 방향(번호가 작아지는 쪽) |
| 주제·난이도 | 몸으로 말해요와 같은 방식. 주제를 여러 개 고르면 라이어가 더 어려워집니다 |
| 설명 바퀴 수 | 1~3바퀴 |
| 한 사람 설명 시간 | 제한 없음 / 15초 / 30초 / 45초. 시간이 다 돼도 저절로 넘어가지 않고 소리로만 알려 줍니다 |
| 라이어에게 주는 정보 | 주제까지 알려주기 / 아무 단서 없이 시작 |
| 투표 방식 | 앱으로 비밀 투표(기기를 돌려 가며 한 명씩) / 손으로 지목하고 결과만 입력 |
| 엉뚱한 사람을 지목하면 | 바로 라이어 승리 / 설명 없이 바로 다시 지목 / 설명을 한 바퀴 더 돌고 재투표. 뒤의 두 가지는 판마다 한 번만 |

라이어는 언제나 한 명입니다. 앱 비밀 투표에서 표가 갈리면 그 자리에서 다시 투표할 수 있습니다.
판이 끝나면 **한 판 더**로 이어 갈 수 있고, 새 제시어와 새 라이어로 다시 시작하면서
시민과 라이어의 전적이 쌓입니다.

## 폭탄 돌리기

기기 하나를 손에서 손으로 넘기는 놀이입니다. 화면에 나온 조건에 맞는 말을 하나 대고
그대로 옆 사람에게 넘깁니다. 폭탄이 터졌을 때 들고 있던 사람이 집니다.

**놀이 중에 누를 것이 없습니다.** 아이들이 말할 때마다 단추를 누르게 하면 놀이가 끊기기 때문에,
넘기기 조작을 아예 두지 않았습니다. 그래서 앱은 지금 누가 들고 있는지 모르고,
터진 사람도 둘러앉은 아이들이 서로 보고 압니다. 앱이 하는 일은 문제를 내고, 시간을 재고,
터뜨리는 세 가지뿐입니다.

**언제 터질지는 아무도 모릅니다.** 남은 시간은 화면에 나오지 않고, 터지기까지의 시간도
판마다 무작위로 다시 정해집니다.

화면 한가운데 **폭탄**이 있고 그 안에 이번 문제가 적혀 있습니다.
폭탄 위로 뻗은 **심지를 불꽃이 타고 내려옵니다.**
다만 이 심지는 **남은 시간을 알려 주는 표시가 아닙니다.** 길이를 이번 판의 실제 길이가 아니라
가장 늦게 터질 수 있는 시각 기준으로 재기 때문에, 심지가 아직 남아 있는데 터지는 판이 있습니다.
게다가 심지는 **일정한 속도로 타지 않습니다.** 한참 멈춰 있다가 갑자기 훅 타들어가기도 해서,
눈으로 재어 터질 때를 짐작할 수 없습니다. 째깍 소리는 시계처럼 일정하게 갑니다.
귀로 듣는 박자까지 흔들면 그냥 어수선해집니다.

터지기 직전에는 **배경이 붉은 경고와 원래 색을 번갈아 깜박입니다.**
터지는 순간에는 화면이 하얗게 번쩍하고 흔들립니다.

**답이 맞는지는 앱이 판정하지 않습니다.** ㄱㅇ이 나왔을 때 무엇을 답으로 인정할지는
그 자리에 있는 사람들이 정합니다. 앱 안에 정답 목록이 있는 것도 아니고,
제시어 데이터와 맞을 필요도 없습니다.

### 무엇이 나오는지

| 종류 | 화면에 나오는 것 | 어떻게 답하는지 |
|---|---|---|
| **초성** | ㄱ ㅅ | 그 초성으로 된 두 글자 낱말 (사과, 수건, 시계⋯) |
| **주제** | 동물 | 그 조건에 맞는 말 (강아지, 사자, 코끼리⋯) |

초성 **63짝**, 주제 **73개**로 모두 **136개**의 문제가 들어 있습니다.

주제 이름은 되도록 짧게 답니다. 폭탄 안 액자에 크게 나와야 멀리서도 읽히기 때문입니다.
"액체인 것"은 "액체", "동물 이름"은 "동물"입니다. 뜻이 흐려지는 것만 예외로 길게 뒀습니다.

### 문제를 고른 기준

**문제마다 답을 스무 개씩 실제로 적어 보고, 스무 개를 채운 것만 넣었습니다.**
적다가 막히는 조건은 놀이가 성립하지 않기 때문입니다. 이 과정에서 여럿이 걸러졌습니다.

| 뺀 것 | 왜 |
|---|---|
| ㅋㅍ, ㅍㄷ, ㅌㄹ 같은 초성 | 커피·포도·통로 몇 개에서 끊깁니다 |
| 태양계 행성 | 답이 여덟 개뿐이라 한 바퀴도 못 돕니다 |
| 소리 나는 것, 냄새 나는 것, 무거운 것 | 거의 모든 것이 해당돼서 맞다 아니다로 다툼이 납니다 |
| 먹을 수 있는 것, 집에 있는 물건 | 너무 넓어서 아무 압박이 없습니다 |

적어 둔 답은 모두 **2640개**입니다. 이 목록은 정답표가 아닙니다.
답이 맞는지는 그 자리 사람들이 정하고, 이 목록은 힌트를 보여 줄 때만 쓰입니다.

### 주제 고르기

설정 화면의 **주제 고르기**에서 나올 주제를 손볼 수 있습니다.

**처음에는 아무것도 골라져 있지 않습니다.** 일흔 개가 넘는 주제를 전부 켜 두고
필요 없는 것을 지워 나가는 것보다, 오늘 쓸 것만 골라 담는 편이 빠르기 때문입니다.
하나도 고르지 않으면 주제 문제가 나오지 않으므로, 설정 화면에서 그 사실을 알려 줍니다.

- 주제를 눌러서 **고르고 빼기**. 뺀 주제는 나오지 않지만 지워지지는 않습니다
- **전부 켜기 / 전부 끄기**
- **우리 반에 맞는 주제 직접 넣기** (예: 급식에 나오는 것). 직접 넣은 주제에는 힌트가 없습니다
- 처음으로 되돌리기 (골라 둔 것이 풀리고 직접 넣은 주제가 지워집니다)

저장하는 것은 "무엇을 골랐는지"와 "무엇을 더 넣었는지"뿐입니다.
그래서 앱을 새로 배포해 기본 주제가 늘어나도 저 혼자 켜지지 않고, 골라 둔 것은 그대로 남습니다.

초성은 여기서 다루지 않습니다. 초성은 취향이 아니라 낱말이 있느냐 없느냐의 문제이기 때문입니다.

### 힌트가 없는 주제

**우리 반 친구, 가수, 영화 제목, 노래 제목** 네 개는 답 목록이 비어 있습니다.
답이 얼마든지 나오는 것은 뻔하지만 미리 적어 둘 수가 없기 때문입니다.
반 친구 이름은 그 자리마다 다르고, 가수는 적어 둔 예시가 몇 해만 지나도 낡습니다.
어차피 답은 그 자리 사람들이 대는 것이라 목록이 없어도 놀이는 그대로 굴러가고,
힌트를 켜도 이 네 주제에서만 예시가 뜨지 않습니다.

같은 문제가 또 나와도 놀이에는 지장이 없으므로, 방금 나온 세 판 것만 피하고 그 뒤로는 다시 나올 수 있습니다.

### 설정

| 항목 | 고를 수 있는 것 |
|---|---|
| 무엇을 낼까요 | 초성 / 주제 / 섞기 |
| 난이도 | 쉬움(힌트 있음) / 어려움(힌트 없음) |
| 폭탄 길이 | 30초 / 60초 / 90초 중에서 고르거나, 20초부터 150초까지 십 초 단위로 직접 정하기 |
| 터지기 직전에 빨라지기 | 켜면 막판에 째깍 소리가 빨라집니다. 끄면 끝까지 일정해서 전혀 눈치챌 수 없습니다 |

**난이도는 힌트를 줄지로만 정합니다.** 나오는 문제는 쉬움과 어려움이 똑같습니다.
어떤 문제가 쉬운지는 아이마다 다르기 때문입니다. 공룡을 좋아하는 아이에게 공룡 이름은
쉬운 문제고, 관심 없는 아이에게는 두 개에서 막히는 문제입니다. 그래서 문제를 미리
난이도별로 나누지 않고, 막혔을 때 힌트를 줄지 말지로 갈랐습니다.

힌트는 **누를 때마다 하나씩** 나옵니다. 한 번에 하나만 보이고 또 누르면 다른 하나로 바뀌므로,
목록을 통째로 읽어 내려가는 일이 생기지 않습니다.

스무 개를 다 보고 나면 처음으로 되돌아가지 않고 **힌트가 끝났어요**라고 알리고 멈춥니다.
되돌아가면 아이들이 이미 말한 것을 또 말하게 되기 때문입니다.

폭탄 길이로 고른 시간은 **기준일 뿐입니다.** 실제로는 그 앞뒤 십 초 안에서 판마다
무작위로 정해집니다. 60초로 두면 50초에서 70초 사이에 터집니다.
정확히 고른 시간에 터지면 몇 판 해 보고 초를 세게 되기 때문입니다.

가장 짧은 30초는 다섯 명이 한 사람당 대여섯 초씩 쓰면 딱 한 바퀴입니다.
이보다 짧게 잡으면 한 바퀴도 못 돌고 끝나서 조여드는 맛이 없습니다.

참가자 인원이나 이름은 넣지 않습니다. 앱이 순서를 관리하지 않기 때문입니다.
문제는 한 판에 하나로 고정되고, 터진 뒤 다음 판을 시작할 때 새 문제로 바뀝니다.
돌수록 댈 말이 떨어져서 판 뒤로 갈수록 어려워집니다.

## 술래 정하기

술래나 순서를 정할 때 쓰는 도구입니다. 뽑을 인원은 1명에서 3명까지 고를 수 있습니다.

### 손가락으로 뽑기

다 같이 화면에 손가락을 하나씩 올리고 그대로 기다리면, 셋을 센 뒤에 한 명을 뽑습니다.
손가락마다 색이 다른 동그라미가 붙어서 몇 명이 올렸는지 바로 보입니다.
중간에 손가락을 더 올리거나 떼면 처음부터 다시 셉니다.
뽑고 나면 손을 떼도 결과가 남아 있고, 다시 손가락을 올리면 새로 시작합니다.

여러 손가락을 동시에 인식해야 해서 **화면이 넓은 아이패드나 태블릿에서 쓰기 좋습니다.**

### 이름으로 뽑기

이름을 넣어 두고 뽑습니다. 휴대폰처럼 화면이 좁을 때나, 자리에 없는 사람까지 넣고
뽑아야 할 때 씁니다. 넣어 둔 이름은 다음에 열어도 그대로 남아 있습니다.

## 제시어

기본 제시어 **1186개**가 들어 있습니다. 주제 10개에 난이도 2단계이고,
제시어마다 힌트가 2~3개씩 붙어 있습니다.

| 주제 | 쉬움 | 어려움 |
|---|---|---|
| 동물, 음식, 스포츠, 직업, 인물, 사물·학용품, 장소, 행동·동작, 만화·캐릭터 | 60 | 60 |
| 감정 | 46 | 60 |

### 같은 제시어가 겹치지 않는 방식

게임을 시작할 때 조건에 맞는 제시어를 **전부 가져와 섞어 두고 앞에서부터 한 장씩** 꺼내 씁니다.
팀이나 사람이 바뀌어도 이 묶음이 이어지므로, 앞 팀이 쓴 제시어가 다음 팀에 다시 나오지 않습니다.

판이 끝나면 그 판에 나온 제시어를 기억해 두었다가 다음 판에서 뒤로 미룹니다.
그래서 같은 날 두 판, 세 판을 연달아 해도 앞판 제시어가 잘 나오지 않습니다.
이 기록은 설정 화면에서 지울 수 있습니다.

### 제시어 관리

홈 화면의 **제시어 관리**에서 다음을 할 수 있습니다.

- 주제별로 목록을 보고, 제시어와 힌트 내용까지 검색
- 제시어 추가, 수정, 삭제 (주제와 난이도, 힌트 3개까지)
- 한 줄에 하나씩 붙여넣어 **여러 개 한 번에 넣기** (이미 있는 것은 자동으로 제외)
- **내 주제 만들기** (예: 우리 반 친구들, 요즘 유행하는 것)
- 기본 제시어만 처음으로 되돌리기 (직접 만든 것은 그대로 남습니다)
- **JSON 파일로 내보내기와 가져오기** (다른 아이패드로 옮기거나 백업할 때)

## 개발

```bash
npm install
npm run dev
```

빌드는 다음과 같이 합니다. 결과물은 `dist/` 폴더에 생깁니다.

```bash
npm run build
```

`base`를 상대 경로로 잡아 두었기 때문에 `dist/` 폴더를 그대로 어디에 올리든 동작합니다.
GitHub Pages처럼 `https://아이디.github.io/저장소이름/` 같은 하위 경로에 올려도 됩니다.

### GitHub Pages에 올리기

`.github/workflows/deploy.yml`이 들어 있어서, **main 브랜치에 올리기만 하면 자동으로**
빌드하고 배포합니다. 처음 한 번만 아래를 해 두면 됩니다.

1. GitHub에서 빈 저장소를 만듭니다. Pages를 무료로 쓰려면 **공개(public)** 저장소여야 합니다.
2. 이 폴더를 그 저장소에 올립니다.

   ```bash
   git remote add origin https://github.com/아이디/저장소이름.git
   git push -u origin main
   ```

3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
4. Actions 탭에서 배포가 끝나면 `https://아이디.github.io/저장소이름/` 으로 열립니다.
5. 아이패드 사파리로 그 주소를 열고 위의 **아이패드에 설치하기**를 따라 합니다.

그다음부터는 고친 내용을 `git push` 하기만 하면 몇 분 뒤 자동으로 반영됩니다.
아이패드에서는 앱을 껐다가 두 번 열면 새 버전으로 바뀝니다.

### 제시어 데이터 점검

제시어를 고치거나 늘린 뒤에는 아래 스크립트로 확인합니다.

```bash
npm run check:words
```

개수와 함께 다음을 검사합니다.

- **힌트에 정답이 새는지** (제시어의 두 글자 조각이 힌트에 들어가면 걸립니다)
- 제시어 중복, id 중복, 힌트 개수(2~3개), 금지 문자

폭탄 돌리기 데이터는 `npm run check:bomb`으로 따로 확인합니다. 두 가지를 봅니다.

- **문제마다 답이 스무 개인지.** 하나라도 모자라면 배포가 멈춥니다.
  위의 힌트 없는 주제만 빈 목록으로 통과하고, 어중간하게 몇 개만 적힌 것은 걸립니다.
- **초성에 적어 둔 답이 그 초성과 실제로 맞는지.** 첫소리를 계산해서 대조하기 때문에
  `ㅁㅁ`에 `마음`(첫소리는 ㅁㅇ)처럼 눈으로는 반드시 놓치는 어긋남이 걸립니다.
  실제로 처음 작성했을 때 이런 오류가 넷 나왔습니다.

두 점검 모두 배포할 때도 자동으로 돌아가서, 문제가 있으면 배포가 멈춥니다.

| 명령 | 확인하는 것 |
|---|---|
| `npm run check:words` | 전체 제시어 데이터 |
| `npm run check:one 동물` | 한 주제만 |
| `npm run check:game` | 한 판 안에서 제시어가 겹치는지 |
| `npm run check:repeat` | 연달아 여러 판을 했을 때 앞판 제시어가 다시 나오는지 |
| `npm run check:bomb` | 폭탄 돌리기 초성·주제 데이터 |

## 저장되는 것

전부 아이패드 안(localStorage)에만 저장되고 밖으로 나가지 않습니다.

| 키 | 내용 |
|---|---|
| `charades.words` | 제시어 목록 |
| `charades.categories` | 주제 목록 |
| `charades.settings` | 소리 설정, 마지막에 쓴 게임 설정 |

| `charades.liarGame` | 진행 중이던 라이어 게임 |
| `charades.bombGame` | 진행 중이던 폭탄 돌리기 |
| `charades.bombTopics` | 폭탄 돌리기에서 꺼 둔 주제와 직접 넣은 주제 |
| `charades.recentWords` | 지난 판에 나온 제시어 |
